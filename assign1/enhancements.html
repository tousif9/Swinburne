Website Enhancements

Built for Every Visitor

Each enhancement makes Pl@netMatrix easier or more enjoyable to use: photos can be viewed up close, forms give instant feedback, and every page fits comfortably on a phone screen. The effects are built with HTML5 and CSS3 features such as :target, :focus-within, :valid and @keyframes.

Overview

This page lists the four main enhancements added to Pl@netMatrix beyond the basic requirements. Each one explains what it does, how it goes beyond the techniques covered in the labs, and links to where you can see it working.

  1. CSS-only photo lightbox gallery
  2. CSS keyframe animations
  3. Embedded map and expandable care tips
  4. Pure CSS drop-down menu and mobile layout

1. CSS-Only Photo Lightbox Gallery

On the Families, Genera and Species pages, every plant has a photo gallery. Selecting a photo opens it full-screen over a dark background with its caption, and a Close link returns to the plant. It uses the CSS :target pseudo-class: each thumbnail links to the id of a hidden viewer, and .lightbox:target makes that viewer visible with position: fixed.

Techniques used
:target pseudo-class, fixed positioning, object-fit, viewport units (vh)
See it in action
Dipterocarpus alatus gallery, an open lightbox, Dipterocarpaceae gallery

2. CSS Keyframe Animations

Three custom animations bring the site to life. Page headings, cards and form sections fade up when a page loads; the tree logo sways like a tree in the wind when you point at it; and the Identify button gently pulses to draw attention. A prefers-reduced-motion media query turns all animations off for visitors who find motion uncomfortable.

Techniques used
@keyframes, animation, transform, box-shadow with rgba(), prefers-reduced-motion
See it in action
Fading cards on the home page, swaying logo, pulsing Identify button

3. Embedded Map and Expandable Care Tips

The Identify page embeds a Google Map showing where the example plant grows, using a responsive <iframe> that fills the page width. The care tips for the result use the HTML5 <details> and <summary> elements, which open and close with a single click and keep the result tidy.

Techniques used
Embedded external content (<iframe>), HTML5 <details> and <summary>, [open] attribute selector
See it in action
Embedded map, expandable care tips

4. Pure CSS Drop-Down Menu and Mobile Layout

The Explorer item in the menu opens a drop-down with links to Families, Genera and Species. It opens on hover and also on keyboard focus using :focus-within, so it works without a mouse. On screens 700 pixels wide or less, a media query stacks the menu, shows the drop-down links directly, moves the side panels below the content and resizes images to fit. The forms also give live feedback, colouring each field red or green as it becomes valid.

Techniques used
:hover and :focus-within, absolute positioning, @media queries, flexbox, :valid and :invalid
See it in action
Explorer drop-down menu, live form feedback (resize your browser window to see the mobile layout)
