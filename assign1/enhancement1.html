Website Enhancements

Built for Every Visitor

Each of these extras makes Pl@netMatrix easier or more pleasant to use. You can look at photos up close, the forms tell you straight away if something's missing, and every page fits comfortably on a phone.

Overview

Here you'll find every extra feature added to Pl@netMatrix beyond the basic requirements. For each one, you can read what it is, see where it's used (with links so you can try it yourself) and find the tutorials I learned it from. The first four are the main enhancements submitted for marking.

1. Fluid Layout with Hamburger Menu

What it is
Every page is built with relative widths, flexible boxes and media queries, so the layout stretches or shrinks to suit any screen. The six main pages sit in the menu bar. The ☰ button to the left of the logo opens a side menu that slides in from the left and lists every page on the site. It works with a hidden checkbox, the :checked selector and a CSS transform transition.
Where it is applied
Menu on every page, Species page (resize your browser window to see the layout adapt)
Reference(s)
W3Schools: Responsive Web Design, W3Schools: Media Queries, W3Schools: The :checked selector

2. Fixed Navigation Bar

What it is
The menu bar stays at the top of the screen as you scroll, so every page is always just one click away, even halfway down the long Species page. It uses position: sticky, and scroll-padding-top makes sure headings don't hide under the bar when you jump to a section.
Where it is applied
Species page, Genera page, every other page
Reference(s)
W3Schools: How To: Sticky Element, W3Schools: CSS Positioning

3. Photo Gallery with Lightbox

What it is
The Explore page has a photo gallery, and every family, genus and species has its own set of pictures too. Click a photo and it opens full-screen over a dark background, with its caption and a Close button. The viewer is built with the :target selector and fixed positioning.
Where it is applied
Explore page gallery, Families gallery, Genera gallery, Species gallery, an open lightbox
Reference(s)
W3Schools: CSS Image Gallery, W3Schools: The :target selector

4. Flip Cards

What it is
Flip cards show a plant photo on the front. There are four on the home page and one for each of the eight species on the Explore page. Move your mouse over a card, or reach its link with the keyboard, and it turns over in 3D to reveal a fun fact and a link to that plant. It uses perspective, transform: rotateY() and backface-visibility.
Where it is applied
"Meet the Plants" on the home page, Species Flip Gallery on the Explore page
Reference(s)
W3Schools: How To: Flip Card, W3Schools: CSS 3D Transforms

5. Page Rating

What it is
Visitors can rate the Explore page from one to five stars. The stars are radio buttons styled with CSS. As you move the mouse along, every star up to the one you're pointing at lights up, and your choice stays highlighted. The rating is then sent just like any other form answer.
Where it is applied
Explore page
Reference(s)
W3Schools: HTML input type="radio", W3Schools: CSS Combinators

6. Picture Hover Effect

What it is
Pictures respond when you point at them. The main images grow a little and cast a deeper shadow, and gallery thumbnails zoom in, inviting you to click. It uses transform: scale() with a smooth transition.
Where it is applied
family tree on the Explore page, Explore page photo gallery, gallery thumbnails
Reference(s)
W3Schools: How To: Zoom on Hover, W3Schools: CSS 2D Transforms

7. Button and Link Hover Effects

What it is
Every button, such as "Start exploring", "Identify" and "Submit", changes colour, lifts slightly and gains a shadow when you point at it, so it's obvious you can click it. Links in the text are bold with a thick mint underline and light up when you point at them. Links that take you to another page also end with an arrow that nudges forward. The arrow comes from the ::after pseudo-element and attribute selectors such as a[href$=".html"], so links within the same page don't get one.
Where it is applied
Home page buttons, form buttons, Email Me button
Reference(s)
W3Schools: CSS Buttons, W3Schools: CSS Transitions, W3Schools: CSS Attribute Selectors

8. Back to Top Button

What it is
A round ↑ button sits in the bottom-right corner of every page. Click it and the page glides smoothly back to the top instead of jumping, which is especially handy on the long Explorer pages. It uses fixed positioning and scroll-behavior: smooth.
Where it is applied
Species page, every other page
Reference(s)
W3Schools: How To: Smooth Scroll, W3Schools: CSS Positioning

9. Google Map

What it is
The Identify page includes a Google Map showing where the example plant grows. The map stretches to the width of the page and fits neatly on a phone.
Where it is applied
Identify page
Reference(s)
W3Schools: HTML iframe tag, W3Schools: Google Maps

10. Music and Audio

What it is
The profile page has a small player with a forest soundscape of running water, wind and birdsong, made especially for this website. It uses the HTML5 <audio> element with controls and looping.
Where it is applied
Profile page
Reference(s)
W3Schools: HTML Audio

11. CSS Animations

What it is
On the home page banner, the heading rises in one word at a time, and the line "Help us ___ Malaysia's plants" keeps changing between explore, identify, record and protect. Around the rest of the site, headings, cards and form sections fade up gently as a page opens, a soft halo glows around the logo, the tree logo sways like a tree in the wind when you point at it, and the Identify button gently pulses. For anyone who prefers less movement on screen, the animations switch off automatically.
Where it is applied
animated banner words, fading cards, swaying logo, pulsing Identify button
Reference(s)
W3Schools: CSS Animations

12. Expandable Care Tips and Quiz Answers

What it is
On the Identify page, the care tips sit inside a box that opens and closes with one click, so the result stays short and tidy. The quiz answers on the Explore page work the same way. Both use the HTML5 <details> and <summary> elements.
Where it is applied
Identify page, quiz answers on the Explore page
Reference(s)
W3Schools: HTML details tag

13. Live Form Feedback

What it is
As you fill in a form, each field's border turns red while the entry isn't right yet and green once it is, and the section you're working on lights up. It uses the :valid, :invalid and :focus-within selectors.
Where it is applied
Contribution form, Enquiry form
Reference(s)
W3Schools: CSS Pseudo-classes, W3Schools: HTML Form Attributes

14. Site-Map Footer

What it is
Every page ends with a footer that doubles as a site map. It has our mission line, five columns of links to every part of the website, and a bottom bar with contact details, credits and a Back to top link. CSS grid lets the columns rearrange themselves to fit the screen, a wavy leaf-edge border along the top is drawn with a radial-gradient, and each link grows an animated underline from the centre when you point at it.
Where it is applied
Home page footer, every other page
Reference(s)
W3Schools: CSS Grid Layout, W3Schools: CSS Gradients

15. Site Search with Suggestions

What it is
Every page has a search box in the header. As you type, it suggests plant names and pages, such as Cryptocarya alba or "Contribution form", using the HTML5 <datalist> element. The search sits in a white rounded box with a mint Search button inside. Click into it and the box widens and glows mint, thanks to the :focus-within selector and a transition. Even the magnifier is drawn with CSS pseudo-elements.
Where it is applied
Header on the home page, every other page
Reference(s)
W3Schools: HTML datalist tag, W3Schools: How To - Search Button, W3Schools: CSS Gradients

16. Phone-Friendly Pages

What it is
Every page is easy to use on a phone. On screens 700px wide or narrower, a media query moves the search box below the logo, slims down the menu bar, stacks the quick facts and side notes into one column, and turns the link map into a simple indented list. Wide tables can be swiped sideways, and their caption tells you so. The Back to top button gets smaller, and form buttons stretch out so they're easy to tap. The forms also use type="email", type="tel" and type="date", so phones bring up the right keyboard or a date picker.
Where it is applied
Enquiry form (phone keypad for the phone number), Species page table, every other page (open on a phone, or narrow your browser window)
Reference(s)
W3Schools: Media Queries, W3Schools: HTML Input Types, W3Schools: Responsive Table

17. Link Map Diagram

What it is
The Explore page draws a tree diagram linking both families to their genera and species. Behind the scenes it's just a nested list. The connecting lines are drawn with the ::before and ::after pseudo-elements, and each box links to that plant's section. On a phone it becomes a simple indented list.
Where it is applied
Explore page
Reference(s)
W3Schools: CSS Pseudo-elements, W3Schools: CSS Flexbox

18. Family Comparison Chart

What it is
A side-by-side chart compares the two families: their fruit, leaves, smell, size, seeds, range and uses. Each family has its own colour bar, every second row is shaded using :nth-child(even), and the row you're pointing at lights up so it's easy to read across.
Where it is applied
Explore page
Reference(s)
W3Schools: Styling Tables, W3Schools: The :nth-child() selector

19. Custom Fonts and Branded Header

What it is
The website uses three free Google Fonts, saved inside the site and loaded with @font-face so they work even without an internet connection. Playfair Display is used for the site name and page titles, Lora for the other headings and Source Sans 3 for the main text. Each one has a backup, such as Georgia or Arial, just in case. The header fades from mint to teal behind faint leaves and grid lines (a linear-gradient under a background image). It shows the name in two colours with a mint "@", a "Family · Genera · Species" pill that links to the Explorer, and the slogan "Know it. Name it. Save it." A gradient line, drawn with the ::after pseudo-element, finishes it off along the bottom.
Where it is applied
Header on the home page, headings and text on the Species page, every other page
Reference(s)
W3Schools: CSS Web Fonts, W3Schools: CSS Gradients, Google Fonts
