Website Enhancements

Built for Every Visitor

Each enhancement makes Pl@netMatrix easier or more enjoyable to use: photos can be viewed up close, forms give instant feedback, and every page fits comfortably on a phone screen.

Overview

This page lists every enhancement added to Pl@netMatrix beyond the basic requirements. For each one it explains what the enhancement is, where it is applied (with links to see it working) and the references used to learn it. The first four are the main enhancements submitted for marking.

1. Fluid Layout with Hamburger Menu

What it is
Every page uses relative widths, flexible boxes and media queries, so the layout stretches or shrinks to fit any screen. The six main pages sit in the menu bar, and the ☰ button on the left of the logo opens a side menu that slides in from the left with every page on the site. It uses a hidden checkbox, the :checked selector and a CSS transform transition. On phones the search box moves under the logo and the menu links shrink to fit.
Where it is applied
Menu on every page, Species page (resize your browser window to see the layout adapt)
Reference(s)
W3Schools: Responsive Web Design, W3Schools: Media Queries, W3Schools: The :checked selector, COS10005 Web Development lectures and tutorials

2. Fixed Navigation Bar

What it is
The menu bar stays pinned to the top of the screen while you scroll, so every page is always one click away, even halfway down the long Species page. It uses position: sticky, and scroll-padding-top stops headings from hiding under the bar when you jump to a section.
Where it is applied
Species page, Genera page, every other page
Reference(s)
W3Schools: How To: Sticky Element, W3Schools: CSS Positioning, COS10005 Web Development lectures and tutorials

3. Photo Gallery with Lightbox

What it is
The Explore page has a photo gallery, and every family, genus and species has its own gallery of pictures. Selecting a photo opens it full-screen over a dark background with its caption and a Close button. The viewer uses the :target selector and fixed positioning.
Where it is applied
Explore page gallery, Families gallery, Genera gallery, Species gallery, an open lightbox
Reference(s)
W3Schools: CSS Image Gallery, W3Schools: The :target selector, COS10005 Web Development lectures and tutorials

4. Flip Cards

What it is
Flip cards show a plant photo on the front: four on the home page and a gallery of all eight species on the Explore page. Pointing at a card, or reaching its link with the keyboard, turns it over in 3D to reveal a fun fact and a link to that plant's page. It uses perspective, transform: rotateY() and backface-visibility.
Where it is applied
"Meet the Plants" on the home page, Species Flip Gallery on the Explore page
Reference(s)
W3Schools: How To: Flip Card, W3Schools: CSS 3D Transforms, COS10005 Web Development lectures and tutorials

5. Page Rating

What it is
Visitors can give the Explorer pages a rating from one to five stars. The stars are radio buttons styled with CSS: hovering lights up every star up to the one under the pointer, and the chosen rating stays highlighted. The rating is sent with the form like any other answer.
Where it is applied
Explorer, Families, Genera, Species
Reference(s)
W3Schools: HTML input type="radio", W3Schools: CSS Combinators, COS10005 Web Development lectures and tutorials

6. Picture Hover Effect

What it is
Pictures react when you point at them. The main images grow slightly and cast a deeper shadow, and gallery thumbnails zoom in, inviting visitors to click. It uses transform: scale() with a smooth transition.
Where it is applied
family tree on the Explore page, Explore page photo gallery, gallery thumbnails
Reference(s)
W3Schools: How To: Zoom on Hover, W3Schools: CSS 2D Transforms, COS10005 Web Development lectures and tutorials

7. Button Hover Effect

What it is
All buttons, such as "Start exploring", "Identify" and "Submit contribution", change colour, lift up slightly and gain a shadow when you point at them, so it is clear they can be clicked.
Where it is applied
Home page buttons, form buttons, Email Me button
Reference(s)
W3Schools: CSS Buttons, W3Schools: CSS Transitions, COS10005 Web Development lectures and tutorials

8. Back to Top Button

What it is
A round ↑ button stays in the bottom-right corner of every page. Selecting it glides smoothly back to the top instead of jumping, which is especially useful on the long Explorer pages. It uses fixed positioning and scroll-behavior: smooth.
Where it is applied
Species page, every other page
Reference(s)
W3Schools: How To: Smooth Scroll, W3Schools: CSS Positioning, COS10005 Web Development lectures and tutorials

9. YouTube Video

What it is
A YouTube video is embedded on the Explorer page so visitors can watch and learn without leaving the site. The player keeps a 16:9 shape on every screen size by using a wrapper box with percentage padding.
Where it is applied
Explorer page
Reference(s)
W3Schools: HTML YouTube Videos, COS10005 Web Development lectures and tutorials

10. Google Map

What it is
The Identify page embeds a Google Map showing the region where the example plant grows. The map fills the width of the page and fits phone screens.
Where it is applied
Identify page
Reference(s)
W3Schools: HTML iframe tag, W3Schools: Google Maps, COS10005 Web Development lectures and tutorials

11. Music and Audio

What it is
The profile page has a player with a short forest soundscape of running water, wind and birdsong, made for this website. It uses the HTML5 <audio> element with controls and looping.
Where it is applied
Profile page
Reference(s)
W3Schools: HTML Audio, COS10005 Web Development lectures and tutorials

12. CSS Animations

What it is
On the home page banner the heading rises in word by word and the line "Help us ___ Malaysia's plants" keeps swapping between explore, identify, record and protect. Elsewhere, headings, cards and form sections fade up when a page opens, the tree logo sways like a tree in the wind when you point at it, and the Identify button gently pulses. Visitors who prefer less motion have the animations switched off automatically.
Where it is applied
animated banner words, fading cards, swaying logo, pulsing Identify button
Reference(s)
W3Schools: CSS Animations, COS10005 Web Development lectures and tutorials

13. Expandable Care Tips

What it is
On the Identify page, the care tips for a result are hidden inside a box that opens and closes with a single click, keeping the result short and tidy. It uses the HTML5 <details> and <summary> elements.
Where it is applied
Identify page
Reference(s)
W3Schools: HTML details tag, COS10005 Web Development lectures and tutorials

14. Live Form Feedback

What it is
While visitors fill in the forms, each field's border turns red if the entry is not valid yet and green once it is correct, and the section being filled in lights up. It uses the :valid, :invalid and :focus-within selectors.
Where it is applied
Contribution form, Enquiry form
Reference(s)
W3Schools: CSS Pseudo-classes, W3Schools: HTML Form Attributes, COS10005 Web Development lectures and tutorials

15. Site-Map Footer

What it is
Every page ends with a footer that works as a site map: the logo and mission, five columns of links to every section of the website, and a bottom bar with contact details, credits and a Back to top link. The columns rearrange themselves to fit the screen with CSS grid, a wavy leaf-edge border is drawn along the top with a radial-gradient, and each link grows an animated underline from the centre when you point at it.
Where it is applied
Home page footer, every other page
Reference(s)
W3Schools: CSS Grid Layout, W3Schools: CSS Gradients, COS10005 Web Development lectures and tutorials

16. Site Search with Suggestions

What it is
Every page has a search box in the header. As visitors type, it suggests plant names and pages, such as Cryptocarya alba or "Contribution form", using the HTML5 <datalist> element linked to the search box. The rounded box and button are styled with CSS.
Where it is applied
Header on the home page, every other page
Reference(s)
W3Schools: HTML datalist tag, W3Schools: How To - Search Button, COS10005 Web Development lectures and tutorials
